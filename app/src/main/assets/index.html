Channel API / M3U Playlist

Connect an IPTV JSON channel API or an #EXTM3U playlist URL (with KODIPROP ClearKey DRM tags). NativePlayerActivity will sync and load this channel list automatically.

Play Direct Stream / ClearKey DRM

Launch NativePlayerActivity directly with any HLS (.m3u8), MPEG-DASH (.mpd), or MP4 URL. Optionally provide ClearKey hex KID & Key or a remote ClearKey license JSON URL.
